# Cam Studio - Windows 10 Native

## Build

Generate the Visual Studio project with CMake:

```bat
cmake -S . -B build -A x64 -DJAVA_HOME="path_to/jdk26"
```

Build Release:

```bat
cmake --build build --config Release
```

The `build/` directory is generated by CMake and should not be committed to Git.

---

## Java JDK

This project uses the Java JDK for JNI headers.

Check `CMakeLists.txt` for:

```cmake
set(JAVA_HOME
    "path to your jkd/jdk26"
    CACHE PATH
    "Path to Java JDK"
)

set(JAVA_INCLUDE_DIR
    "${JAVA_HOME}/include"
)

set(JAVA_INCLUDE_WIN32_DIR
    "${JAVA_HOME}/include/win32"
)
```

Replace the `JAVA_HOME` path with the location of your JDK on your machine.

For example:

```cmake
set(JAVA_HOME
    "C:/Program Files/Java/jdk-26"
    CACHE PATH
    "Path to Java JDK"
)
```

## DirectShow BaseClasses

This project uses the legacy DirectShow BaseClasses to implement the Windows 10 virtual camera.

The BaseClasses source used during development is available through:

https://github.com/cplussharp/graph-studio-next

The DirectShow BaseClasses are required to compile the virtual camera.
